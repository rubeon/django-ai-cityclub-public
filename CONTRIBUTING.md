# Contributing to Django AI CityClub

Thank you for considering contributing to this project!

## Development Workflow

We use the Gitflow branching model for development. Please follow these guidelines:

- **Feature branches**: Create a new branch from `develop` (or `main` if `develop` doesn't exist) prefixed with `feature/`.
- **Release branches**: For preparing releases.
- **Hotfix branches**: For urgent fixes.

## Testing

All new code must include tests. Aim for at least 80% coverage using pytest or a similar testing framework.

## How to Contribute

1. Fork the repository.
2. Create your feature branch.
3. Commit your changes.
4. Push to the branch.
5. Open a pull request.

Please ensure your code adheres to the project's coding standards.
